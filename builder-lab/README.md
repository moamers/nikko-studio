# Builder Lab

A safe sandbox for learning to build games and apps with Claude as a coach. Separate from the Nikko Studio website — nothing here touches `site/`.

**For the parent**
- Start a Claude Code session in this repo and have him say what he wants to make. Claude reads `CLAUDE.md` here and follows a coaching loop: ask, shrink, predict, build, get his feedback, teach one idea, log it.
- `my-journal.md` is his progress record: what he built, words he learned, ideas for later. Worth reading together now and then.
- Each project is a folder in `projects/` and runs by double-clicking `index.html`. No installs, no internet.
- To tune the coaching style, edit `CLAUDE.md`.

**For him**
Open `projects/star-catcher/index.html` in a browser. Play it. Then ask Claude: *"Can you show me how to make it harder?"*
